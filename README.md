# STEP Semester 3

This repository contains my STEP Semester 3 coursework, including weekly assignments and practice problems written in Java.

## Repository Structure

- `main` — Documentation only
- `dev` — Empty Java project skeleton
- `feature/week1` — Week 1 assignments and practice problems
- `feature/week2` — Week 2 assignments and practice problems
- `feature/week3` — Week 3 OOP assignments
- `feature/week4` — Week 4 constructors and Java keywords assignments and practice problems
- `feature/week5` — Week 5 access modifiers, encapsulation, and object-modeling assignments and practice problems

Each weekly feature branch keeps its solutions under the following structure:

```text
src/main/java/weekN/
├── assignments/
└── practice_problems/
```

The weekly branches are intentionally kept separate and are not merged into `dev` or `main`.
